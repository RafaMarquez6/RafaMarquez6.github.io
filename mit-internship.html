Impact Logger for a Robotic Fish

I helped an MIT undergraduate build an impact logger for a 10 lb, 3D-printed fish. The electronics sit inside the fish and record how hard it hits when it's dropped.

The first sensor, an AltIMU-10 v3, could only measure up to ±16g, which isn't enough for a hard impact. I suggested replacing it with the Adafruit ADXL375, which measures up to ±200g, and wrote the Arduino code that records and displays the data.

The parts

ADXL375 accelerometer

Measures acceleration on three axes, up to ±200g. Wired to the Arduino's I2C pins.

Arduino Uno R4 WiFi

Runs the code and creates its own WiFi network, so no router or internet is needed.

GPS + logging shield

Saves every recording to an SD card and tags each session with the last GPS location.

Magnetic switch

Closing the box starts a recording, so nobody has to press a button.

How a test works

  1. Trigger. Close the magnetic switch, or click Trigger Recording on the logger's webpage.
  2. Record. After a 3-second delay, the board records every sensor reading for 7 seconds, with no filtering.
  3. Save. Each reading is written straight to its own file on the SD card (REC001.CSV, REC002.CSV and so on). The board's memory can't hold 7 seconds of data, so the card is required.
  4. View. A laptop joins the board's WiFi and opens its webpage. The page shows a graph, the raw numbers and the biggest change in force. You can switch between recordings or delete them.
